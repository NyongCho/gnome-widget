# 제목 크기와 카드 여백 — 2026-11-04

GNOME 50.1 / NVIDIA RTX 3080의 격리된 Devkit 세션에서 합성 일정·날씨·음악 데이터로 캡처했다. 사용자 계정이나 비공개 일정은 포함하지 않는다.

- [실제 높이와 제목 글꼴](sizes.json)

공통 제목은 약 13px에서 15px로 커졌다. 카드 높이는 표시 중인 내용에 맞춰 측정하며, 비어 있는 상태 메시지는 레이아웃에서 숨긴다. UI scale 1에서 날씨 252→230px, 네트워크 210→177px, 시스템 174→154px, 음악 174→111px를 확인했다. 6주 달력이나 일정 세 개처럼 내용이 많은 카드는 필요한 높이를 확보한다. 날씨 오류 메시지는 230→255px로 확장되고 복구 시 230px로 돌아온다.

검증: `./scripts/check.sh` (TypeScript 61개 포함), `./scripts/test-gnome.py --compact`, `--visual`, 기본 기능 검사 모두 최종 exit 0. compact 검사는 실제 자식 actor의 하단과 카드 하단 사이 여백, 오류/복구 높이, 빈 일정, 한국어/영어, UI scale 1.5, 좁은 화면, 디스플레이 125%와 동일 높이 시계 갱신의 glass cache 보존을 검사한다. 기능 검사는 크기/위치가 바뀐 카드의 배경 갱신, 일반 창 아래 입력, DING/BMS 공존 8회 클릭, 20회 재활성화와 설정창을 포함한다.

기존에 기록된 재활성화 검사의 간헐 실패가 한 번 재현됐다(`cycle=1 roots=0 state=2`). 제품 lifecycle 코드는 바꾸지 않았고, 이어진 전체 실행은 20회 모두 통과했다. 별도 코드 검토에서 조치할 사항은 없었다.

설치한 확장 8개 파일이 배포 ZIP과 일치하고, 확장 설정 보존 및 서비스 active/enabled를 확인했다. 새 코드 적용은 로그아웃 후 로그인해야 한다.
