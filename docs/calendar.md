# Google Calendar 연결

설치 후 위젯 설정 → **데이터 → Google Calendar**에서 비공개 iCal 주소를 입력하고 **연결**을 누른다. 주소는 입력창에서 즉시 지우고 GNOME 키링에 저장한다. 계정 로그인·주소 복사는 사용자가 직접 한다. 채팅이나 프로젝트 파일에 주소를 넣지 않는다.

Google Calendar의 웹 설정에서 해당 캘린더 → **캘린더 통합 → iCal 형식의 비공개 주소**를 찾을 수 있다. 조직 계정은 관리자가 이 항목을 제한할 수 있다. [Google 공식 안내](https://support.google.com/calendar/answer/37648?hl=ko).

연결할 때 키링이 잠겨 있으면 암호 및 키/Passwords and Keys에서 로그인 키링을 먼저 해제하고 다시 시도한다. 백그라운드 수집은 잠금 해제 프롬프트를 반복해서 열지 않는다. URL은 `https://calendar.google.com/calendar/ical/.../private-.../basic.ics` 형식이며 공개 Google iCal 주소도 지원한다. 다른 호스트나 리디렉션을 따라가지는 않는다.

월간 달력은 오늘과 일정이 있는 날을 표시한다. 다음 일정은 진행 중인 일정부터 최대 세 개이며, 끝난 일정은 제외한다. 종일 일정의 종료일은 포함하지 않는다. 카드 클릭은 기본 URI 처리기로 Google Calendar 홈을 연다. 로그인과 사용할 Google 계정 선택은 브라우저에서 처리한다.

## 동기화와 오프라인

활성 구독이 있을 때 5분마다 조회한다. HTTP 요청은 15초, 원본 ICS는 5MiB, 확장은 10000건으로 제한한다. 월·시간대·주 시작 요일이 바뀌면 새 컨텍스트로 다시 계산한다. 자정에는 30일 일정 범위를 새로 계산하도록 갱신한다. UI 컨텍스트와 다른 응답은 일정으로 표시하지 않는다.

원본 캐시는 `~/.cache/liquid-widgets/calendar-<source UUID>.ics`에 마지막 수신 시각과 함께 저장한다. 실제 경로는 XDG_CACHE_HOME을 따른다. 폴더 0700, 파일 0600이며 URL 자체는 들어가지 않는다. 인터넷이 끊기면 원본으로 현재 범위를 재계산하고 `stale`과 원래 수신 시각을 유지한다. 같은 사용자 권한으로 실행하는 다른 프로그램까지 격리하는 저장소는 아니다.

**연결 해제**는 먼저 연결을 비활성화하고 표시 중인 일정과 해당 앱의 모든 캘린더 캐시를 지운다. 키링 삭제가 실패하면 비활성 상태를 유지하고 ‘연결 정보 삭제가 남아 있음’을 표시한다. 키링을 해제한 뒤 **연결 정보 삭제**를 다시 누르면 된다. 저장 장치 오류 등으로 작업을 끝내지 못하면 성공으로 표시하지 않는다.

URL 교체는 새 source UUID의 키링 항목에 먼저 저장하고 설정을 반영한다. 저장 실패는 이전 연결을 바꾸지 않는다. 설정 저장 도중 실패해 생긴 미참조 키링 항목도 연결 해제 시 앱 식별자로 정리한다. 비밀값은 GetSettings, provider payload, 일반 설정, 오류 메시지에 포함하지 않는다. 세션 D-Bus는 동일 사용자 프로세스에 대한 비밀 격리 경계가 아니다. 키링 어댑터는 [Secret Service 라이브러리](https://docs.rs/secret-service/5.2.0/secret_service/)의 암호화 세션을 사용한다.

## 검증 범위

`./scripts/check.sh`는 오프라인 재계산, 출처 변경, 연결 해제·재시작, 원래 성공 시각 유지, 크기·HTTP 실패와 실제 격리 키링을 검사한다. 키링 검사는 임시 XDG 경로와 private D-Bus에서만 실행하며 실제 사용자 키링을 사용하지 않는다.

`./scripts/test-gnome.py`는 테스트 일정으로 날짜 점·진행 중 우선·종료 제외와 컨텍스트 불일치 차단을 검증한다. 격리된 기본 URI 처리기가 `https://calendar.google.com/`를 받은 것도 확인한다. 개인 계정 로그인이나 실제 사용자 브라우저 프로필을 검증한 것은 아니다.

공개 Google 휴일 피드의 실제 HTTPS·ICS 형식 검사는 명시적으로 실행한다:

```bash
./scripts/dev cargo test --manifest-path daemon/Cargo.toml --test calendar_feed live_google_public -- --ignored
```

2026-11-04에 공개 대한민국 휴일 피드를 받아 2026년 10월 범위를 파싱했다. 개인 비공개 피드 연결과 로그인된 브라우저 사용 확인은 사용자 설정 후 남아 있다. 지원하지 않는 반복 규칙과 정확성 범위는 [일정 엔진 검증](calendar-feasibility.md)을 참고한다.
