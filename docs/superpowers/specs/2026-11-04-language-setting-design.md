# 한국어·영어 표시 언어

사용자 요청: 설정에서 영어와 한국어를 선택한다.

위젯 설정 첫 페이지에 `언어 / Language` 선택을 제공한다. 선택지는 `한국어`, `English`이며 기본값은 기존 UI와 같은 한국어다. 선택은 앱의 GSettings `language` (`ko` 또는 `en`)에 저장한다. 위젯, 설정창, 오류·동기화 상태, 접근성 이름, 날짜·요일·월·종일 표시가 즉시 같은 언어로 바뀐다. 시간대·12/24시간·주 시작 요일은 기존 시스템 설정을 따른다.

설정창을 다시 만들지 않고 문구만 갱신해 입력 중인 주소·도시, 검색 결과, 연결 상태를 보존한다. 일정 제목·곡명·아티스트·도시 등 외부에서 받은 내용은 원문을 유지한다. OS 언어, 캘린더 연결, Rust 수집 프로토콜은 변경하지 않는다. 언어 변경으로 네트워크 수집을 재시작하지 않는다.

## 방식

OS gettext만 사용하면 앱 설정으로 즉시 언어를 바꾸기 어렵다. 페이지 전체 재생성은 입력과 비동기 상태를 잃을 수 있다. 기존 TypeScript 구조에 공용 한국어/영어 메시지 사전과 언어별 Intl locale을 두고, GTK 문구 바인딩과 Shell 재렌더링을 연결한다. 새 의존성은 추가하지 않는다. 이는 요청을 구현하기 위한 구현자 선택이다.

## 확인

공용 formatter의 두 언어와 오류/빈 값, 실제 GTK에서 키보드로 양방향 변경 및 입력·상태 유지, 실제 Shell 위젯의 날짜/문구 변경과 재활성화 시 저장값 복구를 확인한다. 캡처는 기존의 격리된 GNOME 테스트와 합성 일정으로만 만든다. 설치한 Shell 코드는 Wayland 특성상 재로그인이 필요할 수 있으며 현재 세션을 강제 종료하지 않는다.
