# Liquid Widgets v0.1.1

A smaller public TypeScript/GJS package for **GNOME Shell 50 on Wayland**, with the same widgets and settings as v0.1.0.

## Changes

- Select the public backend during the build, excluding unused Rust session and transport code from the public extension.
- Generate separate validation modules so the calendar worker includes only the validators it needs. Input validation, error handling and schemas are preserved.
- Reduce the ZIP from **504,900 to 362,079 bytes (28.3%)**, and uncompressed contents from **4,306,052 to 2,788,185 bytes (35.2%)**. The calendar worker bundle drops from 887,235 to 94,383 bytes.
- Keep JavaScript readable and unminified, with unchanged calendar engine, timezone data and complete license notices.
- Add regression checks for both editions to prevent unused backend/validator code and build warnings from returning.

The personal Rust edition remains supported with separate settings and credentials. This release's installable asset is the public GJS edition.

## Install or update

Download **`liquid-widgets.shell-extension.zip`** and **`SHA256SUMS`** from this release's assets. In the download folder, run:

```sh
sha256sum -c SHA256SUMS
gnome-extensions install --force liquid-widgets.shell-extension.zip
```

Log out and log back in, then run:

```sh
gnome-extensions enable liquid-widgets@nyongcho.github.io
gnome-extensions prefs liquid-widgets@nyongcho.github.io
```

Existing public-edition settings are retained. New users can choose a language in **Widgets → Language**, then configure the city and calendar under **Data**. Calendar sync requires libsecret and a session Secret Service, such as GNOME Keyring. The installed public extension does not require Rust, Node.js, npm or a separate systemd service.

## Verification

Two independent reviewers checked the cleanup. All 15 validators matched their previous behavior across 6,480 comparisons, including individually bundled validators. Both-edition checks passed: 97 Rust tests, 143 Node tests, 59 calendar cases per engine, nine native public suites and 26 Python tests. Three explicit live Rust probes remain ignored.

Release packaging checks passed. The exact release ZIP installed, enabled, collected local data, opened production preferences, disabled and uninstalled in a disposable GNOME Shell 50 session without a Rust service. Its internal file contents match the independently verified cleanup build.

These checks do not exercise a private Google account, external weather requests or physical login/lock transitions. The long desktop performance benchmark was not repeated for this build-only cleanup.
