# Liquid Widgets v0.1.0

The first public TypeScript/GJS release of Liquid Widgets for **GNOME Shell 50 on Wayland**.

## Highlights

- Glass desktop widgets for the clock, monthly calendar, upcoming events, weather, CPU and RAM, network activity, and now-playing media.
- Four clock faces, independent left and right columns, configurable sizing and placement, light and dark appearance, and adjustable wallpaper refraction.
- English and Korean interfaces, with Google Calendar iCal integration, Open-Meteo weather, and MPRIS media metadata.
- A public extension that runs with GNOME/GJS. Installing the ZIP does not require Rust, Node.js, npm, or a separate systemd service.

## Install

Download **`liquid-widgets.shell-extension.zip`** from this release's assets. In the download folder, run:

```sh
gnome-extensions install --force liquid-widgets.shell-extension.zip
```

Log out and log back in, then run:

```sh
gnome-extensions enable liquid-widgets@nyongcho.github.io
gnome-extensions prefs liquid-widgets@nyongcho.github.io
```

Choose your language in **Widgets → Language**, then configure the city and calendar under **Data**. Korean is the initial default. Calendar sync requires libsecret and a session Secret Service, such as GNOME Keyring.

Download `SHA256SUMS` alongside the ZIP to verify it:

```sh
sha256sum -c SHA256SUMS
```

## Scope and limitations

- Supported target: GNOME Shell 50 on Wayland; tested on Ubuntu 26.04.1 with Shell 50.1.
- This is a GitHub release. The extension has not yet been submitted to or approved by extensions.gnome.org.
- Calendar integration is read-only. Calendar cards open Google Calendar in the browser; they do not edit events.
- CPU temperature depends on available hardware sensors. The music card needs a playing MPRIS-compatible application; artwork depends on what the player exposes.
- The personal Rust edition remains in the repository with separate settings and credentials. This release's installable asset is the public GJS edition.

This ZIP passed the public package policy and all 12 packaging tests. In a disposable GNOME Shell 50 session, it installed, enabled, collected local system/network data, opened preferences, disabled, and uninstalled without starting a Rust service. The package contents match the previously verified public build. These checks do not use a personal Google Calendar account or exercise physical login and lock transitions.
